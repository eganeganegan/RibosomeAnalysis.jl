The exported API is grouped below. Each entry is sourced from the same docstring shown by Julia's help mode.

Structures and selections

RibosomeAnalysis — Module

RibosomeAnalysis provides reproducible structural, binding-site, interaction, alignment, trajectory, and statistical analyses for ribosomal systems.

The package reports geometric evidence separately from chemical or functional interpretation. Optional extensions provide CairoMakie plots and PythonCall/MDAnalysis trajectory readers.

Alignment and geometry

RibosomeAnalysis.AlignmentResult — Type
AlignmentResult

Rigid-body transform and correspondence diagnostics returned by align_structures, including RMSD, coverage, matches, and unmatched residues.

source
RibosomeAnalysis.match_residues — Function
match_residues(reference, target; chain_map=nothing)

Match RNA and protein residues by global sequence alignment within corresponding chains. With no chain_map, identical chain IDs are paired only when their polymer types agree. An explicit map must refer to existing polymer chains, be one-to-one, and pair compatible polymer types.

Known residues are compared by their one-letter identity. Unrecognized or modified residues match only when their case-normalized residue names agree. Return matched residue pairs and the unmatched residue keys from both inputs.

Dynamics and statistics

RibosomeAnalysis.TrajectoryData — Type

In-memory trajectory.

coordinates has shape 3 × atoms × frames in Angstrom. When present, unit_cells has shape 3 × 3 × frames; each column is a periodic-cell vector in Angstrom.

source
RibosomeAnalysis.TrajectoryFrame — Type

One streamed trajectory frame, with coordinates and cell vectors in Angstrom.

source
RibosomeAnalysis.load_trajectory — Function

Extension point for trajectory readers. Install PythonCall and MDAnalysis for XTC/TRR/DCD.

source
RibosomeAnalysis.foreach_trajectory_frame — Function

Visit trajectory frames one at a time through the optional MDAnalysis reader.

The callback receives a TrajectoryFrame. Its coordinate and cell arrays are independent copies and remain valid after the callback returns.

source

residue_rmsf(structure, trajectory; kwargs...)

Aggregate aligned per-atom RMSF by residue using the root mean square of the atom RMSF values. Trajectory atom identifiers must map to atom indices in the supplied structure.

Return a residue-level geometric contact fingerprint over trajectory frames. Indices are trajectory-local and residue identities are recovered through the trajectory-to-structure atom mapping. Contact fractions do not measure binding affinity or interaction energy.

State comparisons

RibosomeAnalysis.StateMetadata — Type
StateMetadata

User-supplied biological and experimental annotations for a structure state. These labels are never inferred from coordinates.

source
RibosomeAnalysis.ComparisonResult — Type
ComparisonResult

A labeled pairwise state comparison containing the alignment, scalar metrics, changed-contact table, and explicit limitations.

source
RibosomeAnalysis.compare_states — Function
compare_states(items; cutoff=5.0)

Summarize binding-site geometry and supplied metadata for each (structure, ligand, state_metadata) tuple in a DataFrame. State labels and biological annotations are supplied by the caller, not inferred.

source
RibosomeAnalysis.summarize_state_replicas — Function
summarize_state_replicas(observations; state=:state, replica=:replica,
                         value=:value, time=nothing, kwargs...)

Reduce each correlated trajectory replica to one estimate, calculate within-replica moving-block intervals, and summarize independent replica estimates with equal replica weighting. When time names a column, observations are sorted chronologically within each replica before block resampling; otherwise input row order is preserved.

source
RibosomeAnalysis.pairwise_state_differences — Function
pairwise_state_differences(replica_summary; kwargs...)

Calculate target-minus-reference differences between state-level replica estimates. Intervals are omitted unless both states have at least two independent replicas.

source
RibosomeAnalysis.compare_state_ensembles — Function
compare_state_ensembles(observations; kwargs...)

Run replica-aware state summarization and pairwise comparison for a per-frame metric table. The result includes per-replica, per-state, and difference tables plus explicit statistical assumptions.
