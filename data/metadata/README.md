# Dataset metadata

No external biological dataset is redistributed here. Record each acquired
structure or trajectory with accession, download URL, retrieval date, checksum,
organism, construct, experimental method, resolution, assembly definition,
ligand chemical-component ID, and primary citation. Prefer RCSB PDB mmCIF
biological assemblies and preserve their author/label identifier namespaces.

The file in `test/fixtures/` is synthetic geometry for software tests and has no
biological interpretation.
